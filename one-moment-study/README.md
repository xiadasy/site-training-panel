# 一刻 · 番茄学习助手

给备考和学习用的网页番茄钟。不装 App，打开就能用；源码放在自己的仓库里，方便改、方便备份。

在线使用：<https://xiadasy.github.io/site-training-panel/one-moment-study/>

本地打开 `index.html` 也可以。改源码后运行：

```bash
python3 build.py
node test-core.js
```

## 能做什么

- 默认 25 / 5 / 15，每 4 轮长休；可切刷题、听课、背记
- 到点前台响铃、振动；未确认时每 8 秒再提醒一次
- 任务按科目记录：安全管理、安全技术、安全实务、安全法规
- 学习记录里看备考起点到今天的科目累计小时
- 完成后可写：刚才学会了什么、下次从哪继续
- 数据在当前浏览器本地，支持导出 / 导入 JSON

## 闹钟能做什么、不能做什么

网页闹钟在**页面开着、前台可见**时最稳。

锁屏、切到别的 App、或关掉页面后，iPhone 通常不能准时响。这是浏览器限制，不是这个页面漏做了。需要锁屏必响时，请另设系统闹钟。系统通知要授权，且仍受系统限制。

## 科目学时怎么算

学时按任务上的科目累计，只计专注时长，休息不计入。提前结束的实际分钟会记入学时，但不算完整番茄。备考起点和考试日可在设置里改，默认考试日为 2026-10-26。

换手机或换浏览器不会自动同步。请用「导出数据」带走 JSON，再到新页面恢复。
